# ⚽ Football League – Инструкции за инсталация

## Стъпка 1 – Стартирай XAMPP
1. Отвори **XAMPP Control Panel**
2. Стартирай **Apache** и **MySQL** (натисни Start до всеки)

---

## Стъпка 2 – Създай базата данни
1. Отвори браузъра и влез в: **http://localhost/phpmyadmin**
2. Кликни на таб **SQL** (горе в менюто)
3. Отвори файла `football_league.sql` с Notepad
4. Копирай **целия** текст и го постави в полето в phpMyAdmin
5. Натисни **Go** (долу вдясно)
6. Трябва да видиш: ✅ `Базата данни е готова!`

---

## Стъпка 3 – Стартирай приложението
1. Отвори папката `FootballLeague`
2. Отвори `FootballLeague.sln` с **Visual Studio 2022**
3. Натисни **Ctrl+Shift+B** (Build)
4. Натисни **F5** (Run)

---

## Ако имаш грешка при връзка с базата
Отвори файла `FootballLeague/App.config` и провери:
```xml
connectionString="server=localhost;port=3306;database=football_league;uid=root;pwd=;charset=utf8mb4;"
```
- `uid=root` – потребителят на MySQL (по подразбиране е `root`)
- `pwd=` – паролата (по подразбиране е празна в XAMPP)

## Функционалности
| Модул | Описание |
|-------|----------|
| 🏟️ Клубове | Добавяне, редакция, изтриване на клубове |
| 👤 Играчи | Управление на играчи по клуб и позиция |
| 🔄 Трансфери | Записване на трансфери между клубове |
| 🏆 Лиги | Създаване на лиги, участници, генериране на програма |
| ⚽ Мачове | Мачове, резултати, голове, картони, фалове |
